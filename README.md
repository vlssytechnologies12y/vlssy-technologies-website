# VLSSY Technologies — Modern Next.js Redesign

A redesigned, calmer and more premium homepage for VLSSY Technologies.

## Design direction
- Modern AI/product-company visual language
- Smaller, focused hero instead of a text-heavy opening
- Soft off-white, deep navy and restrained coral accent
- Abstract AI visualization built in CSS
- Product-style AI workspace and LMS dashboard
- Shorter copy with clearer hierarchy
- Reusable Next.js components and existing pages retained
- Responsive layout for desktop, tablet and mobile

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Production

```bash
npm run build
```

The project uses `output: 'export'`, so the static site is generated in `out/` and can be deployed to Cloudflare Pages/Workers.
